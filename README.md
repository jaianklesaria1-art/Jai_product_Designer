# Jai Anklesaria, Product Designer

An interactive portfolio: a room at a desk in Mumbai. Click the screens and objects to explore.

- **Left screen**: case studies (Jai designing in Figma)
- **Right screen**: freelance client sites (code + live preview)
- **Pegboard**: experience, as 3D lanyard badges
- **Window**: the story, printed as a train ticket
- **Phone**: contact

Static site, no build step. Run locally with any static server, for example:

```
python -m http.server 8767
```

then open http://localhost:8767.
